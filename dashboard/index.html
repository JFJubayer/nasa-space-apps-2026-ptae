    Scoring method

    Method

    Weighted Gaussian similarity over slope mean/std, TRI mean/std, and elevation std, plus an additive environmental bonus of up to +5 points.

    ACI = min(99.99, 100 × Σ(wᵢ · exp(−½(Δᵢ/σᵢ)²)) / Σwᵢ + environmental bonus)

    Only an exact match on all positively weighted metrics reaches 100; otherwise the cap is 99.99.

    About PTAE

    Project scope, prototype behavior, and intended use.

    Current project

    Planetary Terrestrial Analog Engine

    NASA Space Apps Challenge 2026

    PTAE explores how terrestrial terrain signatures can be compared with lunar and Martian targets. This browser prototype contains catalog-listed Earth candidates, loads target rankings from JSON result files, and presents the historical window-sensitivity analysis separately.

    Photo credits are shown with each image. New catalog-site photos are sourced from Wikimedia Commons and linked to their license and source pages.

    Current prototype scope

    Data and method

    The Python pipeline calculates terrain metrics and ranks candidate signatures. The dashboard reads the generated target JSON files and separate window-sensitivity validation JSON. Map imagery has separate provider attribution and is not live telemetry.
